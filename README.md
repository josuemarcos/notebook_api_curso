# README

This API is a notebook manager. With it is possible to:
- Create, modify, list and delete contacts
- Create, modify, list and delete contact address, phone number etc
- The users can only manage his/her own contacts, with the authentication (JWT)
- It is possible to search contacts with query parameters in the URL, since you start the elastic search service (Using docker-compose up in the main file)
- The API documentation will be available in /api-docs (under construction)
